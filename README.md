# Эмулятор командной строки (Вариант №18)

Кроссплатформенный эмулятор терминала с графическим интерфейсом (GUI) на базе библиотеки Tkinter. Программа работает с виртуальной файловой системой (VFS), которая полностью загружается в оперативную память из ZIP-архива.

## Поддерживаемые команды
* `ls` — просмотр содержимого текущего или указанного каталога.
* `cd` — смена текущей директории.
* `head` — вывод первых строк файла (по умолчанию 10, поддерживается аргумент `-n`).
* `who` — вывод имени текущего пользователя операционной системы.
* `rm` — удаление файла из виртуальной файловой системы.
* `exit` — завершение работы эмулятора.

## Запуск эмулятора

Для удобства проверки и работы автотестера в корне проекта предусмотрены скрипты быстрого запуска:
* **Windows:** Запустите файл `run.bat`
* **macOS / Linux:** Выполните в терминале `./run.sh`

Также поддерживается классический запуск напрямую через Python с возможностью передачи аргументов:

```bash
python3 emulator.py --vfs vfs.zip --script start.txt
--vfs — путь к ZIP-архиву (по умолчанию vfs.zip).
--script — путь к текстовому файлу с командами для автоматического выполнения при старте.
```
## Запуск автоматических тестов

Проект покрыт unit-тестами для проверки корректности алгоритмов виртуальной файловой системы (изоляция путей, чтение, удаление, навигация). Для запуска тестов выполните команду в корне проекта:

```bash
python3 -m unittest tests/test_vfs.py
```

## Примеры использования

Пример сессии работы эмулятора и выполнения стартового скрипта:

```text
--- Выполнение скрипта: start.txt ---
makka@vfs:/$ ls
docs/  notes.txt
makka@vfs:/$ cd docs
makka@vfs:/docs$ head -n 2 test.txt
Line 1
Line 2
makka@vfs:/docs$ cd ..
makka@vfs:/$ rm notes.txt
makka@vfs:/$ ls
docs/
--- Скрипт завершен ---

makka@vfs:/$ who
makka  tty1  pts/0
makka@vfs:/$ exit
