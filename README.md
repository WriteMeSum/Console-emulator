# Эмулятор командной строки (Вариант №18)

Учебный проект по разработке графического эмулятора командной строки на C++.

## Описание проекта
Эмулятор функционирует в оконном графическом режиме и взаимодействует с виртуальной файловой системой (VFS), загружаемой напрямую из ZIP-архива в оперативную память. Распаковка архива на физический диск не производится.

При запуске программы поддерживается чтение и автоматическое исполнение стартового командного скрипта с выводом диалога «команда — результат» в окно терминала.

## Поддерживаемые команды
- ls — вывод содержимого текущей директории.
- cd <path> — смена текущей директории (поддерживаются относительные пути и переход вверх ..).
- head [-n N] <file> — вывод первых строк текстового файла (по умолчанию 10).
- who — отображение информации о текущем пользователе сессии.
- rm <file> — удаление файла из дерева виртуальной файловой системы в памяти.
- exit — завершение работы приложения.

## Сборка и запуск

Для сборки проекта требуется компилятор clang++ с поддержкой C++17.

1. Сборка и запуск эмулятора со стартовым скриптом:
   make run

2. Запуск набора автоматических тестов:
   make test

3. Очистка временных файлов сборки:
   make clean

## Структура проекта
- src/ — исходный код логики VFS, парсера командной строки, оболочки shell и нативного GUI окна (main.mm).
- scripts/ — сценарии запуска (стартовый скрипт start.txt).
- tests/ — юнит-тесты функционала VFS и парсера команд, генератор тестового архива.
