# Эмулятор командной строки (Вариант №18)

Учебный проект по разработке графического эмулятора командной строки на Python.

## Описание проекта
Эмулятор функционирует в оконном графическом режиме (`tkinter`) и взаимодействует с виртуальной файловой системой (VFS), загружаемой напрямую из ZIP-архива в оперативную память. Распаковка архива на жесткий диск не производится.

При запуске программы поддерживается чтение и автоматическое исполнение стартового командного скрипта.

## Поддерживаемые команды
- `ls` — вывод содержимого текущей директории.
- `cd <path>` — смена текущей директории (поддерживаются относительные пути).
- `head [-n N] <file>` — вывод первых строк текстового файла (по умолчанию 10).
- `who` — отображение информации о текущем пользователе.
- `rm <file>` — удаление файла из дерева VFS в памяти.
- `exit` — закрытие окна эмулятора.

## Запуск

Проект написан на чистом Python 3 и не требует установки сторонних библиотек.

1. **Обычный запуск:**
   python3 emulator.py
2. **Запуск со стартовым скриптом:**
   python3 emulator.py --script
